# Target PostgreSQL and Prisma Schema

This document defines the target database structure for the ERP backend.

The target database is PostgreSQL. Prisma is the recommended ORM/migration tool.

## Current Implementation Slice

The first implementation phase is intentionally limited to auth and permissions.

Phase 1 should create only:

```text
companies
branches
users
auth_sessions
subsystems
resources
actions
permissions
scopes
roles
role_permissions
user_roles
user_permission_overrides
audit_logs
```

Phase 1 may seed test metadata such as a demo company, one branch, test
subsystems, test resources, test permissions, and test roles so authentication
and authorization can be verified.

Phase 1 must not create ERP business tables such as invoices, products,
inventory, accounting, or reports.

Implemented Phase 1 files:

```text
prisma/schema.prisma
prisma/seed.ts
src/database/prisma.module.ts
src/database/prisma.service.ts
docker-compose.yml
.env.example
```

The Prisma schema is intentionally limited to auth and permissions. It is valid
and can generate Prisma Client without a live database.

Migration command:

```bash
yarn prisma:migrate:dev --name auth_permission_foundation
```

Seed command:

```bash
yarn db:seed
```

## ID Strategy

Recommended:

```text
String IDs generated by Prisma with cuid()
```

Alternative:

```text
PostgreSQL UUID with gen_random_uuid()
```

Pick one strategy and keep it consistent across the whole ERP.

## Base Columns

Most business tables should include:

```text
id
company_id
created_at
updated_at
deleted_at
created_by_id
updated_by_id
deleted_by_id
version
```

`version` is useful for optimistic locking on important records such as invoices.

## Prisma Skeleton

This is not a final schema file. It is a starting shape for implementation.

```prisma
model Company {
  id          String    @id @default(cuid())
  name        String
  legalName   String?
  nationalId  String?   @unique
  settings    Json      @default("{}")
  isActive    Boolean   @default(true)
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt
  deletedAt   DateTime?

  branches    Branch[]
  departments Department[]
  users       User[]
  roles       Role[]
}

model User {
  id           String    @id @default(cuid())
  companyId    String
  branchId     String?
  departmentId String?
  phone        String
  username     String?
  email        String?
  passwordHash String?
  firstName    String?
  lastName     String?
  isVerified   Boolean   @default(false)
  isActive     Boolean   @default(true)
  isSuperAdmin Boolean   @default(false)
  settings     Json      @default("{}")
  createdAt    DateTime  @default(now())
  updatedAt    DateTime  @updatedAt
  deletedAt    DateTime?

  company      Company   @relation(fields: [companyId], references: [id])
  roles        UserRole[]
  sessions     AuthSession[]

  @@unique([companyId, phone])
  @@unique([companyId, username])
  @@unique([companyId, email])
}

model Permission {
  id          String   @id @default(cuid())
  subsystemId String
  resourceId  String
  actionId    String
  code        String   @unique
  name        String
  isActive    Boolean  @default(true)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  rolePermissions RolePermission[]
  userOverrides   UserPermissionOverride[]

  @@unique([subsystemId, resourceId, actionId])
}
```
